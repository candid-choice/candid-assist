Native Components

In Android and iOS development, a view is the basic building block of UI. React Native lets you invoke these views with JavaScript. At runtime, React Native creates the corresponding Android and iOS views for these components.

Expo vs React Native CLI

If you are new to mobile development, the easiest way to get started is with Expo Go. Expo is a set of tools and services built around React Native. However, if you want to integrate React Native into an existing application, you'll need the React Native CLI.
